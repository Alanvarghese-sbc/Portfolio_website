# Alan Varghese | Full Stack Developer Portfolio

Welcome to my professional developer portfolio repository! This is a sleek, modern, single-page portfolio website designed to showcase my skills, projects, certifications, and academic background.

🌐 **Live Demo**: [Deploy your site to see it live!]

---

## ✨ Features

*   **Custom 3D-Style Particle Background**: An interactive rendering engine built natively on HTML5 `<canvas>` that reacts to mouse movements.
*   **Dual Theme Support**: Dynamically switch between Dark Mode (default) and Light Mode with saved preference using `localStorage` (optimized to prevent visual flashes on reload).
*   **Fully Responsive Design**: Tailored CSS media queries centered on mobile alignments, wrapping columns cleanly on smaller screens, and stacking stats grid boxes dynamically.
*   **Asynchronous Contact Form**: Intercepted submit actions using JavaScript `fetch` API connected to **Web3Forms** for instant email forwarding (AJAX logic, no backend server needed, hides raw email credentials, includes validation/spinner states).
*   **Dynamic Animations**: Integrated Animate On Scroll (AOS) libraries, Typed.js sequencing (types greeting first, then rolls roles dynamically), and 3D card tilts (via Vanilla-Tilt.js).

## 🚀 Local Development Setup

To run this website locally on your computer:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/portfolio.git
    cd portfolio
    ```
2.  **Start a Local Web Server**:
    Since the site utilizes JavaScript ES6 modules and conditional stylesheet parameters, run a local server rather than launching the HTML file directly.
    *   Using Python:
        ```bash
        python -m http.server 8000
        ```
    *   Using Node.js (`serve` package):
        ```bash
        npx serve
        ```
3.  **View in Browser**:
    Open [http://localhost:8000](http://localhost:8000) (or the port specified by your Node server) in your browser.

## 📤 Deployment Guide

To deploy this website to production for free, you can use **GitHub Pages**:

1.  Create a public repository on GitHub.
2.  Push your files to the repository.
3.  Navigate to **Settings -> Pages** in your GitHub repository interface.
4.  Under "Build and deployment", select **Deploy from a branch** and choose **main** (root folder).
5.  Click **Save**. Your site will be published at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`.
